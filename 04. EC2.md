# 🖥️ EC2 (Elastic Compute Cloud)

- Comes under the **Compute** category.
- Provides resizable virtual servers (**processor, RAM**) over the internet in a scalable format.

---

## 🧩 Components of EC2

1. **Instance** — A virtual server.
2. **EBS (Elastic Block Store)** — Storage for the instance over the internet.
3. **ELB (Elastic Load Balancer)** — Distributes load/traffic across multiple servers.
4. **ASG (Auto Scaling Group)** — Increases/decreases the number of servers based on usage.
5. **AMI (Amazon Machine Image)** — Blueprint/template with OS, applications, or app server configuration.

---

## ⚙️ EC2 Instance Types

**Naming:** `Instance Family` + `Generation` + `Additional Capability` + `Size`

**Examples:** `t2.micro`, `r5d.xlarge`

1. **General Purpose** — Family: `T`, `M`  
   Balance of compute, memory, and networking. *Small-scale apps.*

2. **Compute Optimized** — Family: `C`  
   High computational power. *High-end web servers.*

3. **Memory Optimized** — Family: `R`, `X`, `Z`  
   More memory/RAM. *Big data analytics, high-end gaming.*

4. **Storage Optimized** — Family: `I`, `D`  
   More storage. *Storing large amounts of data.*

5. **Accelerated Computing** — Family: `D`, `G`, `P`, `T`  
   GPU-based. *High-end gaming.*

6. **HPC (High Performance Computing)** — Family: `H`  
   High processing, memory, storage, and networking. *Trading systems.*

## 🔑 Key Pairs

A secret key used to securely connect to your EC2 instance.

- **Public Key** — Stored in the AWS console.
- **Private Key** — Stored on your local machine.

### Key File Extensions

1. `.pem` — Privacy Enhanced Mail
2. `.ppk` — PuTTY Private Key

---

## 🚀 Steps to Create an EC2 Instance

1. Go to **AWS Management Console** → Search **EC2** → Click it.
2. In the EC2 console, select **Instances** on the left.
3. Click **Launch Instance** and give it a name.
4. Select the OS (e.g., **Amazon Linux**).
5. Select the instance type (e.g., `t3.micro`).
6. Create a **Key Pair**.
7. Default storage: **8 GB**, expandable up to **64 TB**.
8. Click **Launch Instance**.

---

## 🔐 Steps to Connect to an EC2 Instance

### Using an SSH Client

1. Select the instance → Click **Connect**.
2. Select the **SSH Client** option.
3. Copy the example command.
4. Open Command Prompt from the folder where your private key is stored.
5. Paste the example command.
6. Connection established.

---

## 🪟 Steps to Create and Connect via RDP (Remote Desktop Protocol)

1. Click **Launch Instance**.
2. Select **Windows** as the OS — default storage **30 GB**, expandable up to **64 TB**.
3. Click **Launch Instance**.
4. Select the instance → **Connect** → **RDP Client**.
5. Download the remote desktop file → Click **Get Password**.
6. Upload the private key to decrypt the password.
7. Copy the password, run the remote desktop file, and paste the password.
8. Click **Connect**.
