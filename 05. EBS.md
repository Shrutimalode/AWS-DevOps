# 💾 EBS (Elastic Block Store)

- It is one of the **storage services** provided by AWS.
- It provides **block-level storage**, which is provided in the form of **volumes**.
- Volumes are **Availability Zone specific**.
- Instances are **Region specific**.
- Volumes are also called **Block-Level Storage**.

---

## 📦 Types of Volumes

There are two different types of volumes:

1. **Instance Store Volume** — Default Volume
2. **EBS Volume**

---

## 1. 🗑️ Instance Store Volume

- It is a **temporary block-level storage**.
- It is created when you **launch an instance**.
- It is deleted when you **terminate the instance**.

---

## 2. 💾 EBS Volume

- These are the volumes that are **created by the user**.
- It has to be **deleted by the user itself**.

---

## 🛠️ Steps to Create a Volume

1. Go to **Volumes**.
2. Click on **Create Volume**.
3. Change the **size of the volume**.
4. Change the **Availability Zone** based on which you have launched the instance because volumes are **Availability Zone specific**.
5. Click on **Create Volume**.

---

## 🔗 Steps to Attach Volume to the Instance

1. Select the volume which you want to attach.
2. Click on **Actions → Attach Volume**.
3. Select the instance that you want to attach.

---

## 📝 Notes

> **Note:**

- You can attach a single volume to multiple instances, but first **detach the volume** and then attach it to the next server.
- The minimum size of an EBS volume is **1 GB**.
- It is expandable up to **64 TB**.
- If you want to delete a volume which is connected to the server, first **detach the volume** from the server and then delete the volume.

---

# 🪟 Steps to Create Volume and Attach it to Windows Operating System

1. Create an instance using **Windows OS**.
2. Create a volume and attach it to the instance.
3. Connect the instance using **RDP (Remote Desktop Protocol)**.
4. In the search bar, type **Server Manager** and wait for a few minutes. You will get an option named **File and Storage Services** at the top-left corner.
5. Click on **File and Storage Services**.
6. Select **Disks**.
7. Right-click on the volume which you have created → **Initialize**.
8. Right-click → **New Volume**.
9. Click on **Next → Next → Create**.
10. Go to **File Explorer → This PC** and check the partition.

---

# 🐧 Steps to Create a Volume and Mount it in Linux Operating System

> By performing this, you will be able to get the **backup of the volume using Snapshot**.

1. Create an instance with **Linux OS**.
2. Create a volume and attach it to the instance.
3. Connect to the instance.
