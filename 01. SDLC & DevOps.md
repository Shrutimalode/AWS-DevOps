# 📘 SDLC & DevOps

## SDLC (Software Development Lifecycle)

SDLC is a step-by-step procedure to develop and deploy software.

### Stages of SDLC
1. Requirement Collection
2. Analysis / Feasibility Study
3. Design
   - High Level Design (HLD)
   - Low Level Design (LLD)
4. Development / Coding
5. Testing
6. Deployment
7. Maintenance

### Stage Details

**Requirement Collection**
Collecting the requirements from the clients.

**Analysis / Feasibility Study**
A group of people decides whether or not to take up the project.

**Design**
Creating a blueprint based on the requirements.
- **High Level Design (HLD)** — creates an overview of the project.
- **Low Level Design (LLD)** — creates a detailed blueprint of the project.

**Development**
Based on the design/blueprint, developers write the code.

**Testing**
After developing the software, it has to be tested to make sure it is error-free.

**Deployment**
The application is handed over to the customers/end users.

**Maintenance**
Once deployed, fixing minor issues is called maintenance.

## DevOps

DevOps is a culture/process/approach to develop and deploy an application in a faster way.

### Drawbacks of the Traditional Approach

1. **High Initial Investment**
   - Staff
   - Laptops
   - Infrastructure
   - Networking equipment
   - Storage devices
   - Servers
   - Data centers

2. **Difficult Server Maintenance**
   Servers need to be kept on 24/7, requiring:
   - Heat management
   - Power supply
   - Air conditioning
   - Dedicated staff

3. **No / Less Scalability**
   Increasing or decreasing server capacity is very difficult (e.g., handling a sudden traffic spike like Flipkart's Big Billion Days sale or a viral surge on Instagram).

4. **Limited Accessibility**
   No remote accessibility to servers.

5. **Weak Security**
   Traditional setups often lack robust security compared to cloud environments.
