# ☁️ Cloud Computing

Cloud computing delivers computing resources such as **servers, storage, networking equipment, etc.** over the internet, instead of purchasing and maintaining physical infrastructure. 

Cloud computing is a technology that allow the users to access the computing or IT resources over the internet such as server, storage, database, networking equipment, etc.

---

## ✨ Key Features

### 1. ⚡ On-Demand

Resources such as **servers, storage, and networking equipment** can be obtained instantly whenever required.

### 2. 💰 Pay-As-You-Go (PayG) Model

You pay only for the resources you actually use — similar to an **electricity bill**.

### 3. 🌐 Client-Server Model

Multiple clients (users) send requests over the internet to a server, which processes the request and returns a response.

**Examples:** YouTube, Instagram

---

## 🏗️ Types of Cloud Computing Models

### ☁️ Cloud Deployment Models

### ☁️ Public Cloud

A **Public Cloud** is a cloud computing environment where computing resources such as **servers, storage, and applications** are provided over the internet by a third-party cloud service provider.

**Examples:** AWS, Microsoft Azure, Google Cloud Platform (GCP)

---

### 🔒 Private Cloud

A **Private Cloud** is a cloud computing environment dedicated to a **single organization**. The infrastructure and resources are used exclusively by that organization, providing greater control, security, and customization.

**Example:** A company's own private cloud infrastructure.

---

### 🔄 Hybrid Cloud

A **Hybrid Cloud** is a combination of **Public Cloud and Private Cloud** environments. It allows organizations to use private infrastructure for sensitive data while using public cloud resources for scalability and flexibility.

**Example:** A company stores sensitive customer data in a private cloud while running its web application on AWS.

---

### 🧩 Cloud Service Models

#### 1. 🖥️ Infrastructure as a Service (IaaS)

Provides virtualized servers, storage, networking, and other infrastructure. The customer manages the operating system, applications, and data.

It follows a **Pay-As-You-Go** model and provides flexibility and scalability.

**Example:** Amazon EC2

---

#### 2. 🛠️ Platform as a Service (PaaS)

Provides a ready-to-use platform and environment for developing, testing, and deploying applications. The provider manages the infrastructure and operating system.

**Example:** Google App Engine

---

#### 3. 💻 Software as a Service (SaaS)

Provides ready-to-use software applications over the internet. The provider manages everything, while the user simply uses the application.

**Examples:** Google Workspace, Salesforce, Gmail, Google Drive
