# 🌐 AWS Overview & Global Infrastructure

## ☁️ AWS (Amazon Web Services) — Overview

- AWS is a **subsidiary of Amazon**.
- Launched in **2002**.
- **SQS (Simple Queue Service)** was launched in **2004** — used to maintain communication within an organization.
- In **2006**, AWS officially launched two major services:
  - **EC2** — Elastic Compute Cloud
  - **S3** — Simple Storage Service
- AWS now provides **200+ services** across the globe.

---

## 🌍 AWS Global Infrastructure

AWS Global Infrastructure consists of **4 main components**:

| # | Component |
|---|---|
| 1️⃣ | 🌎 **Regions** |
| 2️⃣ | 🏢 **Availability Zones (AZ)** |
| 3️⃣ | 📍 **Edge Locations** |
| 4️⃣ | 🗄️ **Regional Edge Caches** |

---

### 1. 🌎 Regions

A **Region** is a geographical location specified by AWS.

- **Total:** 39 Regions

---

### 2. 🏢 Availability Zones (AZ)

An **Availability Zone (AZ)** is the location where a Region's data centers are present.

- **Minimum:** 3 AZs
- **Maximum:** 6 AZs
- A Region contains **3 to 6 Availability Zones**.

```text
                    🌎 AWS Region
                         │
          ┌──────────────┼──────────────┐
          ▼              ▼              ▼
       🏢 AZ-1        🏢 AZ-2        🏢 AZ-3
          │              │              │
       Data Center    Data Center    Data Center
```
### 3. Edge Locations

- Data centers present **outside the region**.
- Also called **CloudFront POPs (Points of Presence)** / **CDN**.
- **700+ Edge Locations** globally.
- Located nearest to users to **reduce latency**.

### 4. Regional Edge Caches

- Large data centers present **outside the region**.
- **13 Regional Edge Caches**.
- Without nearby edge infrastructure, distant users face **high latency**.
